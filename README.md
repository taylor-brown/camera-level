# Camera Level

Open `index.html` on a phone (HTTPS required for the camera). Hold the phone sideways and point the camera at what you want to measure.

- Red line: always hangs straight down from the phone's tilt sensor; turns green when level.
- **Angle**: second line at a typed-in angle; glows green when the phone's tilt matches it.
- **Zero**: calibrate. **Photo**: save the frame with the lines drawn on it.

No build step, no dependencies. Works on GitHub Pages as is.
